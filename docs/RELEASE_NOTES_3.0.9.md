# v3.0.9

## 本次更新

- 官方账号的最近请求弹层显示额度重置倒计时，按天、小时表示；不足一小时、已到重置时间和未返回重置时间分别处理，弹层打开时每分钟更新。
- 官方账号新增重置卡总张数和最近一张的到期倒计时、日期；没有卡时显示 0。张数采用持有数量，避免把“当前可兑换数量为 0”误显示成没有重置卡。只读取卡片信息，不提供自动兑换。
- 重置卡详情暂时不可用时，继续显示官方额度和已知张数，并标明到期时间暂不可用。第三方供应商保持原有额度显示。
- Windows 启动器遇到应用激活超时时继续检查实际调试接口，接口已就绪时正常启动。退出等待从 10 秒调整为 25 秒，并明确说明 Codex 可能仍在系统托盘后台运行；需要强制退出时仍保留确认。
- 注入器升级为 100，浏览器伴侣保持 0.1.28。本次平台安装包采用未签名构建，安装提示和 SHA-256 校验方式见下方说明。
