# v3.0.0

## 本次更新

- 减少宿主空闲唤醒、重复状态写入和无效供应商刷新，同时保留 1 秒本机页面动作响应。
- 最近请求改为仅在弹层真实打开时读取；关闭弹层、页面丢失或宿主退出会取消定时器和在途查询。
- OpenAI Official 会话读取增加账号隔离的增量索引、128 MiB 冷扫描上限和文件间取消。
- Hub 搜索与相对时间更新减少整页重绘；供应商探测在得到高优先级结果后会取消其余请求。
- 浏览器伴侣升级到 `0.1.28`，缓存稳定配置、Origin、会话身份和非导出 HMAC 密钥，并随存储变化精确失效。
- Windows 安装器、两种 macOS 架构包以及伴侣 ZIP/CRX 均从同一 `v3.0.0` 源码和版本标签生成。

## 升级说明

- Windows 直接覆盖安装，不要先卸载；现有 `runtime` 缓存、偏好和配对状态会保留。
- 需要浏览器登录态、Cookie 或 WAF 查询时，请使用本 Release 中的 `CCSwitch-Browser-Companion-0.1.28.zip` 或签名 CRX。

## 验证

- `npm test`: `430/430` 通过。
- Windows 隔离安装、原位升级、runtime 保留和卸载烟测通过。
- Windows 稳定版覆盖安装通过；Codex 根进程 PID 在升级前后保持不变。
- 注入器 `95` 已挂载，Edge 和 Chrome 均以伴侣 `0.1.28` 连接。
