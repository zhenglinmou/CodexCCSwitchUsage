# v3.0.8

## 本次更新

- HTTP 供应商默认直接读取 CCSwitch 本地累计费用和最近请求记录，页脚保持“已用 金额 USD”，本地来源放在详情中。现有 CPA 本地端点及精确允许列表继续保留远端查询能力。
- 本地统计按供应商独立读取，刷新立即读取新记录；即使缺少 API Key 或选择远端模板，也不会因此向未放行的 HTTP 地址或浏览器发起请求。没有记录时显示暂无记录。
- 修复未知余额被显示为“剩余 0”的问题；真实的零余额继续正常显示，只有已用金额时同时显示币种。
- 注入器升级为 98，浏览器伴侣保持 0.1.28。本次平台安装包采用未签名构建，安装提示和 SHA-256 校验方式见下方说明。
