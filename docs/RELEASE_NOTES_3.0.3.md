# v3.0.3

## 本次更新

- 修复 Codex 26.911 输入框结构变化后，余额扩展提示“找不到可挂载的输入框页脚”的问题。优先识别输入区的明确标记，避免内部样式误匹配；保留旧版输入区兼容逻辑。
- 注入器升级为 96，支持在已打开的 Codex 中热替换，余额继续在原生控件之间的可用区域居中显示。
- AgentRouter 最近请求支持浏览器账户日志回退：先通过 API Key 列表验证归属，再按对应 Token 名称查询官方账户日志，并读取可用的官方统计接口。仍使用本地请求关联校验，统计接口失败不会阻断明细展示。
- 浏览器伴侣保持 0.1.28。本次为未签名发布，平台安装提示和 SHA-256 校验方式见下方说明。
